# Bad-Name —— 反例：`name` 不是 kebab-case

目录名与 `name` 都是 `Bad-Name`（大写）—— 两者一致，所以只报 E2 那一条。
但宿主校验 frontmatter 时对 `name` 的格式有硬要求：**只允许小写字母、数字和单个连字符**，
不能首尾出现连字符、也不能连续两个连字符。

最坏的情况是它**不报错**：不合规的技能会被直接跳过，模型侧什么诊断都收不到 ——
表现就是"这个技能好像没装"。

## 正确写法

```yaml
name: bad-name
```

小写、用连字符分词。改完记得同步改目录名（见 `dir-mismatch/`）。

`check_skill.py` 期望：`ERROR: [E2]`。
