# oversize-description —— 反例：描述超过了规范上限（1024 字符）

这份描述长度 **1648 字符**，超过 agentskills 规范的 1024 字符上限（另有 W1：超过 500）。
内容本身没写错（何时该用、何时不该用都在前 500 字里），错的是**体量**：把"常见触发场景"列成了
七十条报菜名。宿主渲染时要么截断、要么整条丢掉，而且这类描述几乎必然是"什么都想做"的信号。

## 正确写法

描述只回答两个问题：**什么时候该用**、**什么时候不该用**，剩下的全部留给正文：

```text
当用户给出模糊需求、而它要交给另一个 AI 去执行时，使用本技能：先分诊，再问询，最后落盘长提示词。
触发信号：需求只有一句话、缺交付物路径、缺验收口径。
不接：单步任务、纯问答检索翻译、用户明确说别问了直接干。
```

`check_skill.py` 期望：`ERROR: [E4]`（描述超过 1024）+ `WARN: [W1]`（超过 500）。
